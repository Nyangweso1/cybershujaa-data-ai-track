## Week 1: Web Scraping

Practised collecting raw information from a live website with Python in Google Colab, building foundational skills in automated data collection and preparation.

## Week 2: Data Wrangling in Python

Used Kaggle's Netflix Shows dataset and followed the six-step data-wrangling process:

1. Discovery
2. Structuring
3. Cleaning
4. Transformation
5. Validation
6. Publishing

The result was a clean dataset with 8,776 rows and 16 analysis-ready columns.
